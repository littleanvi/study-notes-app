# Study Notes App 📚

A simple and user-friendly web application for creating, organizing,
searching, editing, and deleting study notes.

# Features

- Create study notes with a title, subject, and content.
- Edit existing notes.
- Delete notes with confirmation.
- Search notes by title, subject, or content.
- Filter notes by subject.
- Add custom subjects.
- Save notes in the browser using localStorage.
- Display helpful messages when no notes match.
- Responsive design with a soft lavender theme.

# Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser localStorage

# How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Start creating your study notes!

No backend or database installation is required.
